# Signed Windows updates

**Tauri's signed updater is now implemented in v1.1.1.**

See [WINDOWS_UPDATER_SETUP.md](WINDOWS_UPDATER_SETUP.md) for the step-by-step instructions to create your personal signing key, configure your GitHub Releases repository, add GitHub Actions secrets, and publish/test your first signed release.

This project intentionally does not ship a private signing key or a preconfigured third-party GitHub repository.
